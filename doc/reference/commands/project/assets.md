# flutter_shadcn assets

> Install font and icon assets.

## Usage

```bash
flutter_shadcn assets [flags]
```

## Arguments

This command does not define positional arguments.

## Flags

| Flag | Short | Default | Description |
|------|-------|---------|-------------|
| `--icons` |  | `false` | Install icon font assets. |
| `--typography` |  | `false` | Install typography font assets. |
| `--fonts` |  | `false` | Alias for --typography. |
| `--list` |  | `false` | List available assets. |
| `--all` | `-a` | `false` | Install all available assets. |

## Examples

```bash
flutter_shadcn assets --list
flutter_shadcn assets --icons --typography
```
