# flutter_shadcn

Multi-registry CLI for installing Flutter shadcn components.

## Installation

```bash
dart pub global activate flutter_shadcn_cli
```

## Public Commands

```bash
flutter_shadcn init --yes
flutter_shadcn add button
flutter_shadcn add @shadcn/button
```
