# Command Reference

Generated from CLI command metadata. Do not edit these files by hand.

## Components

- [`flutter_shadcn add`](./components/add.md) - Install one or more components or blocks and their closure.
- [`flutter_shadcn remove`](./components/remove.md) - Remove installed components, blocks and orphaned layer files.
- [`flutter_shadcn update`](./components/update.md) - Update installed components from the registry.
- [`flutter_shadcn dry-run`](./components/dry-run.md) - Preview what add would install.
- [`flutter_shadcn list`](./components/list.md) - List available components or blocks, by category.
- [`flutter_shadcn search`](./components/search.md) - Search components and blocks by name, description or tag.
- [`flutter_shadcn info`](./components/info.md) - Show a component's or block's closure, files and api.

## Project

- [`flutter_shadcn init`](./project/init.md) - Install the layer core and generate the app theme.
- [`flutter_shadcn registries`](./project/registries.md) - List configured and discoverable registries.
- [`flutter_shadcn default`](./project/default.md) - Set or show the default registry namespace.
- [`flutter_shadcn sync`](./project/sync.md) - Re-apply the installed closure and locked theme.
- [`flutter_shadcn project`](./project/project.md) - Project repair and cleanup commands.
- [`flutter_shadcn theme`](./project/theme.md) - List and apply registry theme presets.

## Diagnostics

- [`flutter_shadcn reset`](./diagnostics/reset.md) - Clear global CLI-managed cache and home-directory state.
- [`flutter_shadcn doctor`](./diagnostics/doctor.md) - Diagnose the manifest, closure, layout and lock drift.
- [`flutter_shadcn validate`](./diagnostics/validate.md) - Validate the registry manifest against the v2 schema.
- [`flutter_shadcn audit`](./diagnostics/audit.md) - Compare installed files against shadcn.lock.

## Tooling

- [`flutter_shadcn feedback`](./tooling/feedback.md) - Submit feedback or report issues.
- [`flutter_shadcn version`](./tooling/version.md) - Show the CLI version.
- [`flutter_shadcn upgrade`](./tooling/upgrade.md) - Upgrade the CLI to the latest version.
