# flutter_shadcn version

> Show the CLI version.

## Usage

```bash
flutter_shadcn version [--check]
```

## Arguments

This command does not define positional arguments.

## Flags

| Flag | Short | Default | Description |
|------|-------|---------|-------------|
| `--check` |  | `false` | Check for updates. |

## Examples

```bash
flutter_shadcn version --check
```
