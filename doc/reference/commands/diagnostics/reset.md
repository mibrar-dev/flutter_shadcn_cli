# flutter_shadcn reset

> Clear global CLI-managed cache and home-directory state.

## Usage

```bash
flutter_shadcn reset
```

## Arguments

This command does not define positional arguments.

## Flags

This command does not define command-specific flags.

## Examples

```bash
flutter_shadcn reset
```

## Notes

This command affects only global CLI state under the user home directory. It does not remove project files or uninstall the executable.
