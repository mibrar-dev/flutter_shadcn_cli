# flutter_shadcn upgrade

> Upgrade the CLI to the latest version.

## Usage

```bash
flutter_shadcn upgrade [--force]
```

## Arguments

This command does not define positional arguments.

## Flags

| Flag | Short | Default | Description |
|------|-------|---------|-------------|
| `--force` | `-f` | `false` | Force upgrade even if already latest. |

## Examples

```bash
flutter_shadcn upgrade
```
